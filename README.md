Completed as part of the **Deloitte Australia Data Analytics Job Simulation** on Forage. Implements forensic technology routines, mathematical first-digit distributions (**Benford's Law**), and unsupervised machine learning (**Isolation Forests**) to audit corporate transaction journals and isolate fraudulent anomalies.

---

## 📌 Methodologies
1. **Benford's Law Audit**: Tests numerical distributions of ledger entries against theoretical logarithmic probabilities to detect fabricated invoices.
2. **Isolation Forest Machine Learning**: Isolates outliers across high-dimensional feature spaces (transaction amounts, approval hierarchies, and weekend activity).
3. **Forensic Reconciliation**: Generates structured investigative audit leads for corporate compliance review.
